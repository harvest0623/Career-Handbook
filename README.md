## 🧭 建议阅读顺序

1. **先看 01**：把简历按「每个模块 + 原因 + 正反例子」改一遍
2. **再看 04**：对着完整示例简历，直接替换成自己的内容
3. **然后看 02**：简历能拿出手了，再去投递、优化招呼语
4. **看 05 再回头确认方向**：了解各岗位就业行情，确认自己的技术栈押对方向
5. **方向定好后看 08**：对照大一到大四路线图，看自己卡在哪个阶段
6. **笔试面试冲刺看 07 + 06**：刷题规划、面试准备清单
7. **拿到 offer 后看 03 + 09**：对比选公司、谈薪与合同避坑

## ⚡ 速查表（写给没时间看完的你）

**简历结构顺序**：个人信息 → 教育经历 → 专业技能 → 实习经历 → 项目经历 → 校园/实践 → 荣誉奖项 → 自我评价（可删）

**一句话项目写法**：项目介绍（2 ~ 3 句）+ 技术栈 + 3 ~ 4 条实现 + 3 ~ 4 条亮点（带数字）

**打招呼黄金结构**：身份（学校+专业+届别）+ 最相关的经历 + 一个成果/技能 + 表达意向

**校招关键节点**：暑期实习(3 ~ 4月) → 提前批(6 ~ 7月) → 正式秋招(8 ~ 11月) → 补录(11 ~ 2月) → 春招(2 ~ 5月)

**公司规模判断**：人数（小 < 100 / 中 100 ~ 499 / 中大500 ~ 999 / 大 ≥ 1000）+ 融资轮次 + 是否上市 + 是否头部

## ⚠️ 三条底线（全篇反复强调）

1. **真实**：写的每一条都要扛得住面试官追问，编造会当场穿帮
2. **匹配**：一份简历只对一个岗位方向，投前按 JD 改关键词
3. **一页**：在校生简历严格 1 页 A4，导出 PDF 投递（如果有多段实习的话，可以使用一页半或两页）
